Project direction:

* This is a web-first Education Center CRM.
* Backend stack: FastAPI + SQLAlchemy.
* Database: PostgreSQL in the main plan, but SQLite is acceptable for the first local prototype if needed.
* Architecture must stay modular and MVP-first.

Important implementation rules:

* Follow the documented architecture and naming conventions.
* Respect the coding rules from docs/coding_rules.md.
* Keep business logic out of route handlers whenever practical.
* Prefer small, working increments.
* Do not add features outside the documented MVP scope.
* Do not invent extra modules unless they are clearly needed.
* Keep files small and readable.
* Use clear names.
* Avoid “temporary” names like helpers2.py, misc.py, temp_fix.py.
* Route modules should stay thin.
* Service layer should contain orchestration/business flow where needed.
* UI/browser must not become the source of business truth.
