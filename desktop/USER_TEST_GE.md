# CRM-ის საცდელი შემოწმება

ეს ჯერ საცდელი ვერსიაა. შემოწმებისთვის გამოიყენე გამოგონილი სახელები და მონაცემები.

## დაწყება

Windows-ის Downloads საქაღალდეში გახსენი `EducationCenterCRM-Preview-20260914`, შემდეგ — `Start.cmd`. Python, ტერმინალი და სერვერის ხელით გაშვება არ გჭირდება. აპი მონაცემებს იმავე მთავარ საქაღალდეში, `data`-ში ინახავს. პირდაპირ EXE-ით გაშვებაც იმავე მონაცემებს იყენებს.

თუ Windows გაშვებას დაბლოკავს, მომწერე ზუსტად რა შეტყობინებას აჩვენებს; დაცვის პარამეტრები არ შეცვალო.

## პირველი შემოწმება

1. შექმენი საცდელი ცენტრი და შენი Admin. გამოიყენე ახალი საცდელი პაროლი, მინიმუმ 12 სიმბოლოთი.
2. შეამოწმე ფანჯარა: ტექსტი იკითხება? ზომის შეცვლისას ღილაკები ან ველები იკარგება? Tab-ით ველებს შორის გადაადგილება მუშაობს?
3. შექმენი ერთი საცდელი მოსწავლე და მასწავლებელი. ზედა მარჯვენა ანგარიშის მენიუდან გახსენი `Benutzerkonten` და შექმენი Manager ან Teacher. Teacher აუცილებლად მიაბი შექმნილ მასწავლებელს.
4. გამოდი და შედი ახალი ანგარიშით. სისტემამ საწყისი პაროლის შეცვლა უნდა მოგთხოვოს. Manager-ს Admin-ის ანგარიშებისა და ბექაფების მართვა არ უნდა ჰქონდეს.
5. Admin-ით დაბრუნდი. `Mein Profil`-ში აირჩიე პროფილის სურათი. მოსწავლეების გვერდიდან ჩამოტვირთე CSV. მითხარი, ფაილის არჩევისა და შენახვის ფანჯრები სწორად გაიხსნა თუ არა.

## ბექაფის შემოწმება

1. Admin-ის მენიუში გახსენი `Datensicherung`, აირჩიე `Nur Daten sichern` და ჩამოტვირთე მონაცემთა ZIP (ეს ნაბიჯები აპში მონაცემების აღდგენას ამოწმებს).
2. ბექაფის შემდეგ დაამატე მეორე საცდელი მოსწავლე.
3. აირჩიე შენახული ZIP, დააჭირე `Sicherung prüfen` და შეამოწმე ცენტრი და ჩანაწერების რაოდენობა.
4. მხოლოდ სწორი მონაცემების შემთხვევაში მონიშნე დადასტურება, შეიყვანე მიმდინარე Admin-ის პაროლი და აღადგინე.
5. ხელახლა შედი ბექაფში არსებული ანგარიშით. მეორე მოსწავლე აქტიურ სიაში აღარ უნდა ჩანდეს; პირველი და პროფილის სურათი უნდა დარჩეს. წინა მდგომარეობის ავტომატური ბექაფი სიაში უნდა დაემატოს.
6. დახურე ფანჯარა და ისევ გახსენი `Start.cmd`. აღდგენილი მონაცემები უნდა შენარჩუნდეს.

## Admin-ის აღდგენა — სურვილისამებრ

`Benutzerkonten`-ში შექმენი და ცალკე შეინახე `Wiederherstellungscode`. გამოსვლის შემდეგ `Admin-Passwort vergessen?`-იდან ამ კოდით შეცვალე Admin-ის პაროლი. გამოყენებული კოდი მეორედ აღარ უნდა მუშაობდეს. შემდგომი შემთხვევისთვის ახალი კოდი შექმენი.

მომწერე: რომელ ნაბიჯზე იყავი, რას ელოდი და რეალურად რა მოხდა. თუ ყველაფერი სწორად მუშაობს, ესეც საკმარისია; შეცდომისას ეკრანის სურათი დაგვეხმარება. პაროლები ან აღდგენის კოდი არ გამომიგზავნო.

## ადმინისტრატორის წაშლა და თავიდან ტესტირება

- მეორე ადმინისტრატორი: ზედა მარჯვენა პროფილის მენიუ → `Benutzerkonten` → `Konto erstellen`, როლი `Administrator`.
- სხვა ანგარიშის წაშლა: `Benutzerkonten` → შესაბამის ანგარიშთან `Konto endgültig löschen`. მიუთითეთ წასაშლელი ანგარიშის ელფოსტა და თქვენი მიმდინარე Admin-პაროლი. საკუთარი ანგარიშის წასაშლელად ჯერ მეორე ადმინისტრატორით შედით. მასწავლებლის სასწავლო ჩანაწერები, ძველი ბექაფები და შენახული სურათები ამ მოქმედებით არ იშლება.
- სრულიად თავიდან დაწყება: პროფილის მენიუ → `Anwendung zurücksetzen`. ჩაწერეთ `ALLES LÖSCHEN` და მიმდინარე Admin-პაროლი, დაადასტურეთ, სრულად დახურეთ აპი და იმავე მალსახმობით გახსენით. შემდეგ გახსნაზე წაიშლება ცენტრის მონაცემები, ანგარიშები, სურათები და ადგილობრივი ბექაფებიც. არქივი არ შეიქმნება. დაიწყება ახალი ცენტრისა და ადმინისტრატორის რეგისტრაცია.
- გარე საქაღალდეში ადრე ჩამოტვირთული ექსპორტები ამ განულებით არ იშლება.

## პორტატული სრული ბექაფი

`Datensicherung` → `Vollständige Sicherung erstellen` ინახავს პროგრამასა და აქტიურ მონაცემებს ერთად `data/backups/crm-portable-….zip`-ში. აღსადგენად ZIP გახსენით ახალ ცარიელ საქაღალდეში და გაუშვით `Start.cmd`. ძველი ბექაფები, აღდგენის ძველი ვერსიები და ტექნიკური ლოგები ხელახლა არ იფუთება. აპში მონაცემების აღდგენის ტესტისთვის გამოიყენეთ `Nur Daten sichern`-ით შექმნილი მონაცემთა ZIP. პროგრამის განახლებისას მხოლოდ `application` იცვლება, `data` რჩება.
